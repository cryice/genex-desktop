# 输入适配器：文字 / 图片 / CAD / GIS / 点云 → IR

所有输入都是**生成 IR 的证据**，不是几何来源。扫描或识别得到的网格永远不是交付物。

## 文字（任务书）

自然语言或指标表 → J1 `IrBrief`：提取用地面积、容积率、覆盖率、限高、分区、关键要素。每条数字带 `source` 与 `confidence`，争议写入 `conflicts` 与 `questions`。

## 平面图片 / 效果图

用于推断布局与风格（`IrStyleGuide` 的色板、材质族、立面词汇）。图片不还原三维——它只证成 IR，几何仍由算子按参数重建。

## DWG / CAD（`dwg-dxf` + `dxf-ir`）

ODA File Converter 作为**独立进程**（不打包，避免 GPL 传染）把 DWG 转 DXF；`dxf_ir` 用 ezdxf 读图层，按图层名正则提取路宽 / 层数（抓最后一个数字，而非首个）。单位 INSUNITS mm→m 缩放。

## GIS / 影像

GeoServer 叠加、正射影像配准只用于地理参考与底图（`gis-alignment`），不直接生成几何。

## 点云 / 倾斜模型

点云只用于校验保真度（Q4 IoU）与配准，其网格不进入交付。若供应商只给扫描网格，明确告知：这不是孪生，是 diorama。

## 原则

- 任一输入都先过 Q0（清单与场景类已知），再进 IR。
- 证据不足时降级为规则基线并提问，不臆造几何。
- 来源优先级低的输入被高优先级覆盖时，必须保留 `questions`。
