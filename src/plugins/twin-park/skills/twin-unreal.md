# Unreal twin runtime

Unreal is the high-fidelity and simulation target. Generate an importable project/content manifest from OpenUSD layers and Twin IR; do not duplicate business semantics in actor names.

Preserve stable object ids, georeference, LOD and material intent through the import boundary. Large scenes use streaming cells or equivalent layer partitioning. IoT bindings resolve through the manifest and a runtime data adapter, not hard-coded Blueprint paths.

Every export records engine version, source IR version, USD layer versions and validation results.
